# کپچای سایت (App\Captcha)

کپچای قبلی (پکیج `aronlabs/captcha`، تصویر + تایپ کد) حذف شد و یک کپچای **نامرئی proof-of-work** جایش نشست.
کاربر چیزی تایپ نمی‌کند؛ مرورگر در پس‌زمینه یک معمای کوچک SHA-256 حل می‌کند (معمولاً کمتر از یک ثانیه).

## کجاها استفاده شده
ورود، ثبت‌نام، تماس با ما، ثبت سفارش، خبرنامه (فوتر و بلوک صفحه‌ساز)، دیدگاه مقالات و فرم‌های فرم‌ساز.

## استفاده در فرم جدید
```blade
<form method="post" ...>
    ...
    <x-captcha />
</form>
```
```php
$request->validate(['captcha' => \App\Captcha\Captcha::rules()]);
```

## چطور کار می‌کند
- سرور معما می‌سازد: `challenge = sha256(salt . number)` با `number` تصادفی و `salt` شامل زمان انقضا؛ معما با کلید مشتق از `APP_KEY` امضا (HMAC) می‌شود — چیزی در session ذخیره نمی‌شود.
- `public/js/captcha.js` عدد را پیدا می‌کند و در فیلد مخفی `captcha` می‌گذارد. اگر کاربر قبل از حل شدن ارسال کند، ارسال نگه داشته می‌شود و بعد از حل خودکار انجام می‌شود (برای فرم‌های ایجکسی هم).
- هر جواب فقط یک بار پذیرفته می‌شود (cache)؛ بعد از هر ارسال، ویجت خودش معمای تازه حل می‌کند.
- معمای تازه: `GET /captcha/challenge` (محدودیت ۳۰ درخواست در دقیقه).

## تنظیمات (`config/captcha.php` / env)
| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `CAPTCHA_ENABLED` | `true` | خاموش‌کردن کامل |
| `CAPTCHA_MAX_NUMBER` | `100000` | سختی معما (بیشتر = کندتر برای ربات و کاربر) |
| `CAPTCHA_TTL` | `30` | اعتبار معما به دقیقه |

در تست‌ها: `\App\Captcha\Captcha::solvedPayload()` یک جواب معتبر می‌سازد.
